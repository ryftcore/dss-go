# esig — Go port of EU DSS (Digital Signature Services)

A Go port of [esig/dss](https://github.com/esig/dss) (upstream baseline: 6.5.RC1), targeting full interoperability compatibility: XAdES / CAdES / PAdES / JAdES / ASiC signing, extension, and EN 319 102-1 validation.

- Roadmap and module mapping: [PORTING_PLAN.md](PORTING_PLAN.md)
- Porting conventions: [dss/PORTING.md](dss/PORTING.md)
- Go module: `github.com/utain/esig/dss`
